# VectorCraft – издание за Тонекс 2000 ЕООД

Векторен редактор (на база отворения код VectorCraft, лиценз MIT OR Apache-2.0) с добавен модул
**Печатница** за предпечат, рязане и оферти.

## Какво е добавено

### Панел „Печатница“ (Window → Print Shop / икона с ножица в дясната колона)

1. **Услуга** – изберете за какво е файлът:
   | Услуга | Изисквания, които се проверяват |
   |---|---|
   | Дигитален печат | CMYK, обрез 2 мм, изображения ≥150 ppi (препоръчително 250), линии ≥0,25 pt, мастило ≤320% |
   | Офсетов печат | CMYK, обрез 3 мм, изображения ≥200 ppi (препоръчително 300), линии ≥0,25 pt, мастило ≤300% |
   | Широкоформатен печат | изображения ≥50 ppi (препоръчително 100), линии ≥0,5 pt |
   | Стикери с контурно рязане | задължителна линия CutContour, затворени контури, без запълване |
   | Лазерно рязане и гравиране | само вектори, текст в криви, затворени контури, дължина на рязане |
   | CNC фрезоване | като лазер |
   | DTF / DTG печат | изображения ≥150 ppi (препоръчително 250), линии ≥0,5 pt |

2. **Резултат** – зелено „Готов за предпечат“, жълто „За преглед“ или червено „Към дизайн“.
   Под него – всяка грешка/забележка на български; бутон **Покажи** избира проблемните обекти.
   Проверява се още: липсващи шрифтове, текст не в криви, текст под 5 pt, RGB цветове, бели
   обекти на overprint, обекти извън формата, обекти, които свършват точно на ръба без обрез,
   спот (Pantone) цветове, прозрачност.
3. **Формат** – размер на всяка работна област в мм и м².
4. **Рязане** – брой линии, л.м. рязане, площ на детайлите (за оферта).
5. **Направи контур** – около избраните обекти (вектори, текст, снимки по рамката им) се
   създава контур на зададеното отстояние (по подразбиране 2 мм), в спот цвят **CutContour**
   (100% магента), 0,25 pt, без запълване, на отделен слой „CutContour“. С отметка „Един общ
   контур“ – един контур около всичко избрано. Отменя се с една стъпка Undo.
6. **Запиши доклад…** – текстов доклад на български за клиента или към поръчката.

Езикът на интерфейса се избира от Preferences → User Interface → Language → Български.

### Команди (за автоматизация, CLI и MCP)

- `printshop.profiles` – списък на услугите.
- `printshop.preflight {profile, selectionOnly?, minPpi?, recommendedPpi?, bleedMm?, format?: "text"}`
- `printshop.cutStats {mode?: "cutContour" | "allStrokes", names?: [...]}`
- `printshop.cutContour.make {offset?: мм, each?: true, name?: "CutContour", weight?: 0.25, layer?: true}`

Пример – проверка на клиентски файл от командния ред:

```
vectorcraft-cli run --in klient.pdf --cmd printshop.preflight --params "{\"profile\":\"sticker\",\"format\":\"text\"}"
```

## Изграждане за Windows

**Най-лесно (GitHub):** в хранилището → Actions → *Tonex Windows build* → *Run workflow*. След
~30–60 мин. от страницата на изпълнението се сваля `vectorcraft-tonex-windows-x64.zip`.
Разархивира се в папка и се стартира `vectorcraft.exe` (преносима версия – без инсталация).

**Ръчно на Windows** (Rust + Visual Studio Build Tools):

```
set VECTORCRAFT_EDITION=Тонекс 2000
cargo build --release -p vectorcraft -p vectorcraft-cli
```

`VECTORCRAFT_EDITION` слага името на фирмата в заглавието на прозореца, в About и в
свойствата на .exe файла. Без нея се получава стандартният VectorCraft.
